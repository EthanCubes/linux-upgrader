# Linux System Update Script
Linux system upgrader script. Supports apt, dnf, and pacman. *Only supports Linux, no MacOS or Windows*

Made for [Hack Club Bashed](https://bashed.hackclub.com)

## Installation
- Run `curl -fsSL https://raw.githubusercontent.com/EthanCubes/linux-upgrader/refs/heads/main/update.sh | bash` to download and run the script
